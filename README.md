# Desarrollo Justo RD — Sitio estático

Sitio de una sola página (HTML/CSS) para Desarrollo Justo RD, una campaña ciudadana sobre criterios justos en el PMOT de Verón-Punta Cana.

Archivos creados:

- `index.html` — contenido en español y estructura de la página.
- `styles.css` — estilos, paleta teal/coral, responsive.

Despliegue rápido

1. GitHub Pages: crear un repo y subir estos archivos a la rama `main`. En Settings → Pages, seleccionar la carpeta raíz o `docs/`.
2. Netlify / Vercel: sube el proyecto o conecta el repo; son compatibles con sitios estáticos sin configuración adicional.

Notas importantes antes de publicar

- Verificar y añadir enlaces específicos a artículos que respalden las afirmaciones (no dejar solo enlaces a front pages).
- Confirmar los datos de zonificación y cifras (niveles/alturas) antes de hacerlos públicos; incluir notas metodológicas sobre las fuentes.
- Considere revisión legal si la campaña va a publicar alegaciones que puedan ser impugnadas.

Si quieres, puedo:

- Añadir archivos de metadatos (Open Graph) y una imagen de enlace generada.
- Incluir un formulario de recopilación de comentarios (requiere backend o servicio externo como Google Forms).
